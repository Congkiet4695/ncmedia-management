# Đa ngôn ngữ (i18n) — Frontend

> Trạng thái: đã triển khai. Ngôn ngữ hỗ trợ: **Tiếng Việt (mặc định)**, **English**.
> Thư viện: **react-i18next** (`i18next` + `react-i18next`).

---

## 1. Vì sao chọn react-i18next thay vì next-intl

Yêu cầu nghiệp vụ: **đổi ngôn ngữ tức thì, không reload, nhớ bằng LocalStorage, KHÔNG đổi URL.**

`next-intl` gắn ngôn ngữ vào **đường dẫn** (`/vi/...`, `/en/...`) và middleware — dùng đúng cách
thì mỗi lần đổi ngôn ngữ là một lần điều hướng, và toàn bộ route hiện có phải đổi cấu trúc.
`react-i18next` giữ ngôn ngữ trong bộ nhớ phía client, đổi ngôn ngữ chỉ là một lần re-render.
Khu vực Dashboard vốn đã gần như toàn bộ là `'use client'` nên không mất gì khi dùng nó.

Đánh đổi đã biết: `metadata` (tiêu đề tab) do server sinh nên **không** biết ngôn ngữ người dùng
chọn — xem Mục 7.

## 2. Cấu trúc thư mục

```
apps/frontend/
  i18n/
    config.ts                 # NGUỒN SỰ THẬT: danh sách ngôn ngữ, namespace, khoá localStorage
    index.ts                  # khởi tạo i18next (dùng chung server & client)
    resources.ts              # gom các file JSON thành bảng tài nguyên
    locales/
      vi/  common.json menu.json auth.json validation.json employee.json
           account.json order.json report.json pod.json fulfillment.json profile.json
      en/  (đúng 11 file trùng tên với vi)
  providers/i18n-provider.tsx # cấp instance + khôi phục ngôn ngữ đã lưu
  stores/locale.store.ts      # state ngôn ngữ + ghi/đọc localStorage
  components/language-switcher.tsx
  hooks/use-locale-format.ts  # ngày / số / tiền tệ theo ngôn ngữ
  hooks/use-api-error.ts      # error code Backend → câu chữ đã dịch
  config/navigation.ts        # cấu hình menu Sidebar (kèm cờ ẩn)
  scripts/check-i18n.mjs      # kiểm tra tự động (npm run check:i18n)
```

Namespace tách theo **miền nghiệp vụ**, không theo màn hình: một màn hình có thể dùng nhiều
namespace (`useTranslation(['pod', 'common'])`), và một namespace phục vụ nhiều màn hình.

## 3. Dùng trong component

```tsx
'use client';
import { useTranslation } from 'react-i18next';

export function Example() {
  const { t } = useTranslation(['pod', 'common']); // namespace đầu là mặc định
  return (
    <>
      <h1>{t('orders.title')}</h1>          {/* pod:orders.title */}
      <button>{t('common:action.save')}</button>
      <p>{t('orders.itemCount', { count: 3 })}</p>
    </>
  );
}
```

Quy tắc:

- **Không** viết chữ hiển thị thẳng trong component — kể cả `aria-label`, `title`, `placeholder`.
- Ghép câu bằng **tham số nội suy** (`{{name}}`), không nối chuỗi. Trật tự từ mỗi ngôn ngữ mỗi khác.
- Nhãn của `enum` đặt tên khoá **trùng mã enum** để tra bằng khoá động:
  `t(`status.${order.status}`)`. Nhờ vậy thêm trạng thái mới chỉ cần thêm khoá.

### Server Component

`page.tsx` của App Router chạy trên server, không gọi được hook. Cách xử lý: tách phần chữ ra
một client component nhỏ — xem `features/auth/components/auth-card.tsx` và
`app/(dashboard)/dashboard/_components/dashboard-heading.tsx`.

### Ngoài phạm vi React (hook, service)

Import thẳng instance: `import i18n from '@/i18n'` rồi gọi `i18n.t('auth:login.success')`.
Xem `features/auth/hooks/use-login.ts`.

## 4. Validation (Zod)

Schema được tạo bằng **hàm nhận `t`** thay vì khai báo tĩnh, vì câu lỗi phụ thuộc ngôn ngữ runtime:

```ts
export function createLoginSchema(t: TFunction<'validation'>) {
  return z.object({ email: z.string().min(1, t('required')).email(t('email')) });
}
```

Component tạo lại schema khi đổi ngôn ngữ:

```tsx
const { t: tv } = useTranslation('validation');
const schema = useMemo(() => createLoginSchema(tv), [tv]);
```

Áp dụng cho: `auth`, `profile`, `employee`, `pod-tiktok`.

> Hạn chế đã biết: câu lỗi **đang hiển thị sẵn trên màn hình** chỉ đổi ngôn ngữ sau lần
> validate kế tiếp. Không xử lý thêm vì đây là trạng thái thoáng qua.

## 5. Lỗi từ Backend → error code

Backend trả envelope `{ success, code, message, ... }` (ADR-022). Frontend ưu tiên **`code`**:

```tsx
const translateApiError = useApiError();
toast.error(t('orders.sync.failedTitle'), { description: translateApiError(error) });
```

`useApiError` (`hooks/use-api-error.ts`) theo thứ tự:

1. `validation:serverError.<CODE>` nếu có bản dịch → dùng bản dịch.
2. Không có bản dịch → dùng `message` Backend trả về (không mất thông tin).
3. Không có gì → `serverError.INTERNAL_ERROR`.

Nhờ bước 2, **thêm error code mới ở Backend không làm vỡ giao diện**; chỉ là chưa được bản địa
hoá cho tới khi bổ sung khoá. Hiện đã dịch sẵn ~57 code (AUTH, EMPLOYEE, ORDER, ACCOUNT, POD,
FULFILLMENT, STORAGE, IMPORT).

## 6. Ngày, số, tiền tệ

Dùng `useLocaleFormat()` — **không** gọi thẳng `new Intl.*` trong màn hình:

```tsx
const { formatDate, formatDateTime, formatNumber, formatCurrency } = useLocaleFormat();
```

Thẻ BCP-47 lấy từ `getIntlLocale()` trong `i18n/config.ts` (`vi` → `vi-VN`, `en` → `en-US`).

## 7. Thêm một ngôn ngữ mới (ví dụ tiếng Nhật)

1. `cp -r i18n/locales/en i18n/locales/ja` rồi dịch nội dung.
2. Thêm một dòng vào `LOCALES` trong `i18n/config.ts`:
   `{ code: 'ja', label: '日本語', flag: '🇯🇵', intl: 'ja-JP' }`
3. Thêm khối import + một mục trong `resources.ts`.
4. `npm run check:i18n` để chắc chắn không thiếu khoá.

**Không phải sửa** component, provider, switcher hay cấu hình menu. Nút chuyển ngôn ngữ tự sinh
từ `LOCALES`.

## 8. Kiểm tra tự động

```bash
npm run check:i18n
```

Bắt ba lỗi chỉ lộ ra lúc chạy: ngôn ngữ lệch bộ khoá, khoá `t('...')` không tồn tại, và khoá trỏ
vào một nhánh thay vì một chuỗi. Nên chạy cùng `typecheck` và `lint` trước khi merge.

## 9. Ẩn menu tạm thời

Sidebar sinh từ `config/navigation.ts`. Ẩn một menu = thêm `hidden: true` vào đúng mục đó:

```ts
{ labelKey: 'accounts', href: '/dashboard/accounts', icon: ShoppingBag,
  permission: 'account.read', hidden: true },
```

Đây là **ẩn ở tầng giao diện**: route, permission, API, service, database giữ nguyên; gõ thẳng URL
vẫn vào được. Bật lại chỉ cần xoá dòng `hidden: true`.

Hiện đang ẩn: **Account**, **Order**, **Báo cáo** (kèm 5 báo cáo con).

## 10. Giới hạn đã biết

| Vấn đề | Lý do | Ảnh hưởng |
|---|---|---|
| `metadata.title` / `metadata.description` không dịch | Server render không biết ngôn ngữ lưu ở localStorage | Tiêu đề tab dùng tên thương hiệu (trung lập ngôn ngữ) |
| Câu lỗi form đang hiển thị chưa đổi ngay khi chuyển ngôn ngữ | Zod message được "đóng băng" tại thời điểm validate | Đổi ở lần validate kế tiếp |
| Màn hình **Account** và **Order** chưa chuyển hết sang `t()` | Xem Mục 11 | Hai menu này đang ẩn nên không xuất hiện trên giao diện |
